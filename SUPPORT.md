# Support Policy

Lebanon Commerce Toolkit is a free, community-oriented plugin maintained by Pro-Solutions.net.

## Supported requests

- reproducible bugs in the current release;
- compatibility defects on documented WordPress, WooCommerce, and PHP versions;
- accessibility and RTL problems;
- evidence-based corrections to Lebanese administrative labels;
- security reports submitted privately according to `SECURITY.md`.

## Outside community support scope

- emergency production recovery;
- store-specific setup and data entry;
- custom theme/plugin conflict resolution without a minimal reproduction;
- custom shipping-rate design;
- bespoke features, integrations, or migrations;
- guaranteed response times or 24/7 support.

For a useful bug report, include exact versions, checkout type, HPOS status, theme, steps to reproduce, expected result, actual result, and sanitized logs/screenshots. Never post credentials or personal customer data.
