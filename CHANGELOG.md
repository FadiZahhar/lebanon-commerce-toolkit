## [0.1.0] - 2026-08-27

### Added

- Lebanon dataset with 9 governorates and 26 districts in English and Arabic.
- Classic WooCommerce billing/shipping district fields with dependent UI and validation.
- Checkout Block additional address field with country conditions and Store API shipping refresh.
- Stable order metadata using WooCommerce CRUD and HPOS compatibility declaration.
- Lebanese phone normalization, structural validation, and international-number preservation.
- Merchant-controlled informational secondary currency with optional rounding.
- Zone-compatible district delivery method with district/governorate/global fallback rules.
- Dynamic Gutenberg blocks and shortcodes.
- Public read-only locations REST endpoint.
- Admin settings, uninstall choice, test suite, CI, packaging, and release documentation.
